# Упаковка34 — лендинг с Telegram-лидогенерацией

**Живой сайт:** [upakovka34.ru](https://upakovka34.ru)

---

## Что это

Лендинг для b2b-поставщика брендированной упаковки из Волгограда. Клиент работал только через сарафанное радио — не было ни сайта, ни воронки. Задача: запустить онлайн-присутствие и выстроить поток заявок.

---

## Роль

Я выступал как продакт: определил задачу, описал требования, спроектировал структуру страницы и пользовательский путь, проверил результат через CPO-аудит, итерировал.

---

## Задача

- Целевая аудитория — малый бизнес: кофейни, шоурумы, локальные бренды
- Тираж от 2000 шт., средний чек — упаковка с логотипом
- Главный вопрос клиента: «сколько стоит и как заказать»
- Конверсионное действие: оставить заявку → получить в Telegram

---

## Что сделано

### Продуктовые решения
- Определил структуру страницы через CJM: осознание → доверие → действие
- Убрал лишние метрики из hero (заменил «6 шагов» на срок и цену — то, что реально важно клиенту)
- Провёл CPO-аудит после запуска → нашёл 8 правок → итерация
- Настроил Telegram-бот как канал приёма заявок: мгновенное уведомление без CRM

### Технический стэк
- Статический HTML/CSS/JS — намеренно, без фреймворка: быстро, без оверхеда
- Vercel Serverless Function (`/api/submit`) — обработка формы на сервере
- Telegram Bot API — все заявки приходят в чат напрямую
- Vercel — деплой, кастомный домен, безопасные переменные окружения

### Архитектурное решение по безопасности
Изначально Vercel Deployment Protection блокировал endpoint `/api/submit` для всех пользователей, кроме владельца аккаунта. Из-за этого заявки от реальных клиентов не доходили. Проблему диагностировал через curl, отключил защиту через Vercel REST API — все заявки начали приходить.

## Структура проекта

```
├── index.html          # вся страница
├── css/style.css       # стили
├── js/main.js          # логика формы, меню
├── api/submit.js       # serverless: отправка в Telegram
├── img/                # каталог продуктов
├── privacy.html        # политика конфиденциальности
└── vercel.json         # заголовки, кэш, clean URLs
```

---

## Локальный запуск

```bash
npm i -g vercel
vercel dev
```

Нужны переменные окружения:

```
TELEGRAM_TOKEN=...
TELEGRAM_CHAT_ID=...
```

- Сайт индексируется (structured data, OG, canonical)
